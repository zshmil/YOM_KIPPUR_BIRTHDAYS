# YOM_KIPPUR_BIRTHDAYS
A side project I took a part in, Yom Kippur War Memorial Center.

הפרוייקט התחיל מקובץ אקסל שקיבלתי, ולאחר שכתבתי את הwebscraper הראשון, הייתי צריך לעשות עוד עבודה ידנית על הקובץ אקסל ואחרי זה להשתמש בקובץ שיצרתי.
לא יכולתי להעלות לכאן גם את הקובץ אקסל (בגלל הרגישות הרבה של הנושא), אבל הוספתי את כל ההתחלה של הקוד לפני הקובץ ואת ההמשך לאחר מכן.
הוספתי גם חלק קטן של הסקריפט שאפשר ליצור איתו קובץ אקסל זהה לקובץ שקיבלתי מראש (אני מודע לכך שיכולתי לכתוב משהו קצת יותר כדי ליצור את האקסל, אבל רציתי
פיתרון מהיר).
אני מזמין את כל מי שיכול לעזור לשפר את הקוד, ללמוד מהקוד או סתם לדבר על הנושא לפנות אלי.



The project began with an Excel file that I received. After building the initial web scraper, I still needed to perform some manual data preparation in Excel before using the processed file as an input for the rest of the workflow.
Because of the sensitivity of the subject matter, I was not able to upload the original Excel file. Instead, I included the code used before the Excel-processing step, as well as the code that continues from that point onward.
I also added a small utility script that can generate an Excel file with the same structure as the original input file. I’m aware that this part could have been implemented in a more robust or automated way, but at the time I intentionally chose a simple solution that allowed me to move forward quickly.
I welcome anyone who is interested in improving the code, learning from it, contributing ideas, or simply discussing the project and its subject matter to reach out to me.
